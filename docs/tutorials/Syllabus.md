# Syllabus — learn_sql_query_basic

A SELECT-only SQL course delivered as 23 self-contained hands-on lessons. Each lesson uses a different real-world industry — bookstore, café, vet clinic, ride-share, soccer league, city weather, and others — and ships its own pre-generated SQLite database. The course is wrapped in the learn-this-project methodology: six interactive skills (absorb, quiz, elevate, interview, demo, publish) carry a learner from "just cloned the repo" to "shipped a portfolio version on my own GitHub".

## 01-Learn-This-Project

Work through the 23-lesson SELECT-only SQL course using the six learn-this-project interactive skills (absorb, quiz, elevate, interview, demo, publish). Each lesson is a self-contained folder with a pre-generated SQLite database and worked queries that explain both the business question and the design rationale. After completion you can translate plain-English business questions into SELECT queries — filtering, joins, subqueries, CTEs, window functions — and ship a portfolio version on your own GitHub.
