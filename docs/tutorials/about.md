# Course Overview

A hands-on SELECT-only SQL course across 23 self-contained lessons, each using a different real-world industry and shipping its own pre-generated SQLite database. The curriculum covers filtering, ordering, aggregation, joins, subqueries, CTEs, set operations, and window functions, wrapped in the learn-this-project methodology with six interactive skills.

After completing it you can translate plain-English business questions into correct SELECT queries against well-shaped schemas, defend the course's design decisions under interview pressure, and ship a clean portfolio version of the repo on your own GitHub.
