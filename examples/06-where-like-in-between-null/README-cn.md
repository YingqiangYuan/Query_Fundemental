# Lesson 06 — LIKE / IN / BETWEEN / IS NULL

> 等号查得了完全相等的值，但生活中我们经常想问 "以 The 开头的"、"价格在 10 到 20 之间的"、"还没填的"。这节课就把这几把更趁手的筛选刀子学会。

## 我们要学什么

这节课在 `WHERE` 的基础上，加入四把比 `=` 更灵活的筛选工具：

| 构件 | 一句话 |
|------|--------|
| `LIKE 'The %'` | 模糊匹配：以 "The " 开头的标题 |
| `LIKE '_he %'` | `_` 通配符匹配单个字符（"The" 和 "She" 都中） |
| `IN (...)` | 等于列表里的任何一个值 |
| `NOT IN (...)` | 不在这个列表里的值 |
| `BETWEEN a AND b` | 落在两个值之间（**两端都含**） |
| `IS NULL` / `IS NOT NULL` | 判断空值的**正确写法**（`= NULL` 永远是错的） |

这几把刀子是日常查询里出现频率最高的几个——
学完之后，你能直接用一行 `WHERE` 表达八成的业务筛选需求。

## 数据库故事

这节课的练习数据是一家小型连锁影院某两周的**电影场次表**。

| 表名 | 内容 | 行数 |
|------|------|------|
| `showtimes` | 每一场电影的排片信息（片名、影院、放映厅、起止时间、分级、原声语言、字幕语言、票价） | 50 |

故意只用一张表，让你专注在筛选语法本身。
注意：`subtitle_lang`（字幕语言）这一列**很多行是 NULL**——表示这场放映只有原声、没字幕。后面例子里我们就靠这种"没填"的特性来练习 `IS NULL`。

## 先自己探索一下

正式开始前，**强烈建议你先自己动手点一点**：

- 在 DBeaver 左侧栏里展开 `showtimes`，双击表名预览数据。
- 看每一列叫什么、值大概长什么样：`screen_number` 都有哪些放映厅？`rating` 都有哪些分级？`language` 是不是只有英语？
- **特别留意 `subtitle_lang` 这一列**——你会看到大量的空格（NULL），还有一部分是 "English"、"Spanish"、"French" 之类。

预先在脑子里建立这种"画面感"，你后面跑查询的时候就能预判结果，比起对着陌生数据猜，学得快得多。

## 关于 SQL 注释（小知识）

你会发现每个 example 文件里都有一大堆以 `--` 开头的文字。
SQL 有两种注释写法：

```sql
-- 单行注释：从 -- 到这一行结尾的内容都被数据库忽略。

/*
 * 块注释：可以跨多行。
 * 写长一点的说明很方便。
 */
```

数据库**会直接忽略**注释，所以你随便写，**不会影响**查询结果。
我们在每个 example 文件里把"业务问题"和"为什么这么写"都用注释写在 SQL 旁边，
就是希望你以后回过头来看也能立刻想起这条 SQL 在干嘛——
注释和代码住在一起，比单独翻教程要省事得多。
