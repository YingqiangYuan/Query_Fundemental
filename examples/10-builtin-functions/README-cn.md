# Lesson 10 — 内置函数

> 数据库里存的字符串、数字、日期，常常不是你想要的样子。本节课教你用 SQLite 的"自带工具箱"——内置函数——把它们就地整理成你想要的形状。

## 我们要学什么

这节课的主题是 **SQLite 自带的内置函数**：不需要你额外装任何东西，写在 `SELECT` 里就能直接用。
我们会按"操作的数据类型"把常用函数分成四类，再加一个专门处理 NULL 的小节：

| 分类 | 代表函数 | 一句话 |
|------|----------|--------|
| 字符串 · 大小写与长度 | `UPPER`, `LOWER`, `LENGTH`, `TRIM` | 把字符串规范化（统一大小写、去掉空格、量长度） |
| 字符串 · 切片与替换 | `SUBSTR`, `REPLACE`, `INSTR` | 截取一段、替换子串、找位置 |
| 数字 | `ROUND`, `ABS`, `CAST` | 四舍五入、取绝对值、强制类型转换 |
| 日期 | `date()`, `strftime()`, `julianday()` | 规整日期格式、按月分桶、算两日之差 |
| NULL 处理 | `COALESCE`, `IFNULL` | 当某列是 NULL 时给一个"备胎"值 |

学完这一节，你就能在 SQL 里直接做"清洗 + 格式化"，不必把数据先导出到 Excel 或 Python 里再处理。

## 数据库故事

这节课的场景是一个**公立图书馆的借阅记录**。

| 表名 | 内容 | 行数 |
|------|------|------|
| `checkouts` | 每一条借阅记录（借阅人姓名、邮箱、书名、借出日期、应还日期、归还日期、滞纳金） | 50 |

数据故意"不太干净"——这样才好练手：

- 有些 `member_name` 前后带了多余空格（练 `TRIM` 和 `LENGTH`）。
- `member_email` 来自多种域名（gmail / yahoo / outlook / hotmail / icloud / 多所大学 .edu），方便练 `SUBSTR` 切域名、`REPLACE` 改域名。
- 还没还书的借阅 `returned_date` 是 NULL；没产生滞纳金的 `late_fee` 也是 NULL——专门留给 `COALESCE` / `IFNULL` 用。

## 关于 SQL 注释（小知识）

每个 example 文件都用大量 `--` 开头的行来写说明。SQL 的两种注释写法：

```sql
-- 单行注释：从 -- 到这一行结尾，都被数据库忽略。

/*
 * 块注释：可以跨多行。
 * 写长一点的说明很方便。
 */
```

数据库**完全忽略**注释，你怎么写都不影响查询结果。我们把"业务问题"和"为什么这么写"都贴在 SQL 旁边——以后你回过头来再看，一眼就能想起这条查询在干嘛。
